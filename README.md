# Anki-карточки: английский B1–B2

- **Приложение для iPhone:** https://bogdaryan.github.io/anki-cards/ — открыть в Safari,
  «Поделиться» → «На экран „Домой“». Работает без интернета, прогресс хранится на телефоне.
- **Колода Anki:** [decks/английский-b1-b2.apkg](decks) — 1000 выражений, 2000 карточек, 11 подколод
  по темам. Открывается двойным щелчком в Anki на компьютере.

Каждое выражение — две карточки: «Понять» (английская фраза → значение) и «Сказать»
(русская фраза → сказать вслух по-английски).
