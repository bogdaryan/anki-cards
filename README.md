# Anki-карточки: английский B1–B2 и C1–C2

- **Приложение для iPhone:** https://bogdaryan.github.io/anki-cards/ — открыть в Safari,
  «Поделиться» → «На экран „Домой“». Работает без интернета.
  - уровни на выбор: B1–B2, C1–C2 или оба (C1–C2 по умолчанию выключен);
  - новых в день — 10, 20, 30 или без лимита;
  - профили: у каждого свой прогресс; прогресс хранится только на устройстве.
- **Колоды Anki** (папка [decks](decks), открываются двойным щелчком в Anki):
  - `английский-b1-b2.apkg` — 5000 выражений, 10 000 карточек, 32 темы;
  - `английский-c1-c2.apkg` — продвинутый уровень, отдельной колодой.

Каждое выражение — две карточки: «Понять» (английская фраза → значение) и «Сказать»
(русская фраза → сказать вслух по-английски).
